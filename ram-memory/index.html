RAM & Memory Modifications

Note: You cannot fake physical RAM size through registry edits.

A. Increase Dedicated Video RAM (VRAM) Allocation

  1. Open regedit.
  2. Go to HKEY_LOCAL_MACHINE\SOFTWARE\Intel (or AMD equivalent).
  3. Create key GMM.
  4. Create DWORD (32-bit) value DedicatedSegmentSize.
  5. Set Base to Decimal and value in MB (e.g., 512, 1024, 2048).
  6. Restart your computer.

B. Fix High RAM / Memory Leak Issues

  1. Open regedit.
  2. Go to HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Ndu.
  3. Open Start and change value from 2 to 4.
  4. Restart your computer.

C. Change the Windows Boot Splash/Startup Logo Safely (HackBGRT)

Windows does not include a native setting to change the very early UEFI boot logo. For that, people typically use HackBGRT (download from official releases).

  • Prerequisites: Your system should be using UEFI boot mode.
  • Secure Boot: Depending on your setup, you may need to disable Secure Boot for HackBGRT to run.
  • Prepare splash.bmp: use a small square image on a black background and save it as a 24-bit BMP file.
  1. Extract HackBGRT and run setup.exe as Administrator.
  2. When prompted, choose I to install.
  3. Replace/edit the image as instructed so your logo is saved as splash.bmp.
  4. Complete setup, then reboot and verify the new splash logo.

To restore the original behavior, run setup.exe again as Administrator and choose R.

Warning: Bootloader/UEFI modifications can affect bootability. Back up important data first and always follow the latest instructions in the official HackBGRT documentation before making changes.

D. Use RAM and CPU at Full Advertised Performance

  1. Enter BIOS/UEFI and enable your memory performance profile: XMP (Intel), EXPO (AMD), or D.O.C.P./E.O.C.P. (board-vendor naming).
  2. In Windows, enable the Ultimate Performance plan (if available): 
    powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
  3. CPU core parking tweaks are optional. They can help some latency-sensitive workloads but may increase heat/power use without meaningful gains in other scenarios.
Setting Area Default Behavior Performance-Profile Behavior Trade-Offs
RAM Frequency/Timings JEDEC-safe baseline speeds XMP/EXPO/DOCP profile applies advertised kit settings Higher heat and possible instability on marginal CPU/board combos
Windows Power Plan Balanced power-saving behavior Ultimate Performance reduces aggressive power-saving transitions Higher idle/overall power use
CPU Core Parking Windows parks/unparks cores based on load Reduced parking can keep more cores active Workload-dependent gains; can increase temperatures and fan noise

After any performance tuning, run stability tests and monitor system behavior. Use tools such as HWiNFO or HWMonitor, and keep temperatures within safe ranges defined by your CPU/GPU manufacturer rather than relying on one universal limit.
