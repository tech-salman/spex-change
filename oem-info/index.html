Change OEM Manufacturer and Model Info

Customize manufacturer, model, and support fields shown in System Properties.

  1. Open regedit.
  2. Go to HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion.
  3. Create OEMInformation key if it doesn't exist.
  4. Inside it, create String Values: Manufacturer, Model, SupportPhone, SupportHours, SupportURL.
  5. Double-click each value and enter your custom text.
  6. Restart your PC to apply changes.
