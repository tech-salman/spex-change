Fix “Some settings are managed by your organization”

These restrictions usually come from Group Policy keys or linked work/school accounts.

Method 1: Clear policy keys via Command Prompt

  1. Run Command Prompt as administrator.
  2. Run these commands one by one:
reg delete "HKLM\Software\Policies\Microsoft" /f
reg delete "HKCU\Software\Policies\Microsoft" /f
reg delete "HKLM\Software\Microsoft\Windows\CurrentVersion\Policies" /f
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies" /f
gpupdate /force
  1. Restart your computer.

Method 2: Manually delete restriction keys in Registry Editor

  1. Open regedit.
  2. Check and clean policy subfolders under:
  • HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\
  • HKEY_CURRENT_USER\SOFTWARE\Policies\Microsoft\

Method 3: Disconnect work or school accounts

  1. Open Settings > Accounts > Access work or school.
  2. Disconnect organizational accounts enforcing policies.
