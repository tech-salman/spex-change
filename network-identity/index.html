Change MAC Address and IP Address (No VPN)

Part 1: Change MAC Address

Method 1: Device Manager

  1. Open Device Manager and expand Network adapters.
  2. Open your adapter Properties > Advanced.
  3. Set Network Address / Locally Administered Address.
  4. Enter a 12-digit hexadecimal value (example: 021A2B3C4D5E).
  5. Restart your computer.

Method 2: Registry Editor

  1. Open regedit.
  2. Go to HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Class\{4d36e972-e325-11ce-bfc1-08002be10318}.
  3. Find the adapter key (0000, 0001, etc.) matching DriverDesc.
  4. Create String value NetworkAddress and set your 12-digit hex value.
  5. Restart your computer.

Part 2: Change IP Address

Public IP

  1. Power off the router/modem completely.
  2. Wait 5–10 minutes (sometimes longer).
  3. Power it back on to request a new dynamic public IP.

Local (Private) IP

  1. Open ncpa.cpl via Run.
  2. Open your connection properties and edit Internet Protocol Version 4 (TCP/IPv4).
  3. Select Use the following IP address and enter a valid local IP.
