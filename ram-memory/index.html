RAM & Memory Modifications

Note: You cannot fake physical RAM size through registry edits.

A. Increase Dedicated Video RAM (VRAM) Allocation

  1. Open regedit.
  2. Go to HKEY_LOCAL_MACHINE\SOFTWARE\Intel (or AMD equivalent).
  3. Create key GMM.
  4. Create DWORD (32-bit) value DedicatedSegmentSize.
  5. Set Base to Decimal and value in MB (e.g., 512, 1024, 2048).
  6. Restart your computer.

B. Fix High RAM / Memory Leak Issues

  1. Open regedit.
  2. Go to HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Ndu.
  3. Open Start and change value from 2 to 4.
  4. Restart your computer.
