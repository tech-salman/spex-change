How to Change Your PC Startup Logo

Since native Windows tools cannot modify the boot splash screen, the safest and most effective way to change your PC startup logo is by using HackBGRT, a free, lightweight, open-source bootloader utility[cite: 1].

This method injects your custom image right before Windows boots up without permanently flashing or risking damage to your physical motherboard BIOS.

📋 Prerequisites Before You Start

  1. Verify UEFI Mode: Press Win + R, type msinfo32, and press Enter. Check the BIOS Mode row to ensure it says UEFI. (Note: This tool will not work on older "Legacy" systems).
  2. Disable Secure Boot (Recommended): Restart your PC, enter your BIOS setup screen (usually by spamming F2 or Del at startup), look for Secure Boot, and change it to Disabled.

Step 1: Prepare Your Custom Logo Image

Windows requires a specific format for early boot graphics. You can use MS Paint to set this up easily:

  1. Open your image in MS Paint.
  2. Keep the image relatively small (ideally 300x300 pixels or up to 400x400 pixels so it fits neatly).
  3. Fill the canvas surrounding your image with pure black, as transparent backgrounds are not supported.
  4. Click File > Save As and select BMP picture.
  5. Save the file exactly as splash.bmp and choose 24-bit Bitmap from the drop-down format menu.

Step 2: Download and Run HackBGRT

  1. Go to the official HackBGRT GitHub Releases page and download the latest .zip archive.
  2. Extract the folder to your desktop.
  3. Copy your custom splash.bmp image, paste it directly into the extracted HackBGRT folder, and overwrite the default placeholder file.
  4. Right-click setup.exe inside the folder and select Run as administrator.
  5. A command window will appear. Press the I key on your keyboard to start the installation.
  6. A Notepad configuration text file will pop up next. You can simply close it—the default layout will use your image automatically.
  7. Close the command window and restart your computer to see your new custom startup logo!

🔄 How to Restore Your Default Logo Later

If you ever want to revert back to your original Windows or factory manufacturer logo:

  1. Re-open the HackBGRT folder.
  2. Right-click setup.exe and Run as administrator.
  3. Press the R key (Remove/Restore) in the command prompt window.
  4. Restart your computer, and the system will default back to standard settings.

If you try this and run into issues, check your motherboard brand or ensure Secure Boot settings are properly configured.
